# tileccl

## 依赖

本项目通过 git submodule 引入以下第三方库：

- [`third_party/cutlass`](https://github.com/NVIDIA/cutlass) — NVIDIA CUTLASS
- [`third_party/ThunderKittens`](https://github.com/HazyResearch/ThunderKittens) — HazyResearch ThunderKittens

## 获取代码

```bash
git clone --recursive git@github.com:stmoonar/tileccl.git
```

已经克隆过的仓库：

```bash
git submodule update --init --recursive
```
